# ☕ 永久雇用カフェ

お客さんをスカウトしてアルバイトとして雇い、**永久雇用契約**を結んで**正社員**にしていくカフェ経営ゲームです。
ブラウザだけで動き、スマホでもパソコンでも遊べます。

## 遊び方

1. 下部メニューの**お店**の「調理」（または店内のコンロ）をタップして料理を注文すると、手の空いたスタッフがコンロに入って調理します（数秒〜3分）。できあがったらタップしてカウンターへ並べます。
2. スタッフがカウンターの料理をお客さんへ運び、食べ終わるとお金がもらえます。お客さんは基本的に安い料理から頼みます。汚れたテーブルもスタッフが片付けます。スタッフの仕事は「配膳 → 調理 → 片付け」の順に優先されます。
3. 待たせすぎるとお客さんは怒って帰ってしまいます。
4. お客さんを**タップするとスカウト**できます。雇った人はまず**アルバイト**で、契約期間（1日）が終わると辞めてしまいます。
5. **📜 永久雇用契約**を結ぶと**正社員**になり、ずっと働いてくれます。正社員にできる人数は**正社員の枠**で決まり、店舗ランクを上げると増えます（ショップでは買えません）。正社員はいきなり解雇できず、**アルバイトに降格**すると枠が1つ空き、また契約できます（降格した人は契約期間1日のアルバイトになり、期間が過ぎると辞めます）。
6. お金で**コンロ・テーブル・設備強化・内装**を買ってお店を大きくしましょう。
7. スタッフごとに**持ち場**（ホール／厨房／両方）を決められます。「ホール」は配膳と片付けだけ、「厨房」は調理だけを担当します。
8. 条件（レベル・接客人数・正社員の数）とお金がそろったら**店舗ランク**を上げられます（お店の「🏆 ランク」タブ）。
9. スタッフは**能力**をそれぞれ★1〜5で持ちます。4つの合計から**総合評価**（C／B／A／S／SS）が決まり、スカウト代・引き抜き料・料理勝負の強さに使われます。
   - 💪 **体力**：★1つにつき1日働ける（★3でおよそ3連勤、★5でおよそ5連勤。店長は無限）
   - 🍳 **調理**：調理の速さ
   - 🏃 **配膳**：歩く速さと片付けの速さ
   - 🤝 **忠誠度**：激励・ドリンクできつい台詞が出るまでの回数（★×2回）と、休憩からの復帰の速さ（★3で減る速さの10倍、★1つにつき±15%）

   体力が尽きると奥の壁の **💤 休憩室**で休みます。休憩中は忠誠度に応じた速さで回復し、**満タンになると自動で職場に戻ります**。
   - 休憩室をタップして **💪 激励**：体力が1時間分回復して、すぐ職場に戻る
   - ショップの **🥤 エナジードリンク**（¥200 × 店舗ランク）：スタッフタブか休憩室で飲ませると体力が1日分回復するだけ（激励とは別）。休憩中の人は、飲ませて満タンになれば職場に戻る
   - 激励・ドリンクに回数の制限はない
   - 激励・ドリンク・正社員にしたとき・降格したときに、従業員が店のブラックぶりや店長の非道さを責めるひと言を返す（頭の上のふきだし・お知らせ・休憩室に表示）。同じ人に繰り返すほど言葉がきつくなる。潜入中の激励は「潜入先から電話で」になる
   - 料理勝負に出ている間も、働いているときと同じように体力が減る（尽きたら帰ってから休憩室で休む）
10. **留守中の営業**：アプリを閉じている間（別のアプリに切り替えていた間も）、カウンターの料理と調理中の料理がある間はお客さんが来て売上が入ります（上限時間はなく、料理の在庫がなくなるまで）。できあがった料理は自動でカウンターに並び、担当がいなければ手の空いた人が調理を引き継ぎます。営業している間はスタッフの体力が減り、店を閉めている時間は休んで回復します。
11. **🗺️ 地図**で**引き抜き作戦**ができます（下記）。

## 引き抜き作戦（🗺️ 地図）

主人公は22歳の女性店長。街にはライバル店（すべて架空の NPC 店）が並び、15分ごとに入れ替わります。店舗ランクを上げるほど格の高い店（E → D → C → B → A → S）が現れます。

- **⚔️ 料理勝負**（主に格下の店へ）：スタッフを最大3人送り出し、時間が経つと結果が出ます。勝率は「メンバーの総合力（能力の平均）の合計＋引き抜いたレシピの数＋コンロ強化」と相手の強さで決まり、結果は勝利・大成功・敗北。勝つとお金のほか、レシピや店員が手に入ることがあります。
- **🕵️ 潜入**（主に格上の店へ）：店長が客のふりをしてライバル店に入り、**客席を自分で歩き回ります**（床をタップで移動）。店内は奥から「🍳 厨房（店員）」「カウンター」「🍽️ 客席」に分かれていて（自分のカフェも同じ造り）、店員はカウンターの向こうの厨房で働きながら、カウンター越しに客席を見張っています。
  - 🪑 席（テーブル席・カウンター席）をタップして座る → 注文して食べる
  - 🚪 カウンターの切れ目にある厨房のスイングドア（STAFF ONLY）の前へ → 厨房をのぞく。見られていなければ成功しやすい
  - 🧑 店員をタップ → カウンターの手前まで行き、店員がカウンターの向こうまで来てくれる → 観察・会話・誘う（カウンターを離れると会話は終わる）
  - 👀 **店員の視線**（黄色い扇形）：歩いているときは進む方向を、立ち止まると左右を見回す。**厨房の扉の前にいるところ**や、**立ち止まってうろうろしているところ**（5秒以上）を見られると扇形が赤くなり、警戒ゲージが上がる。見られていなければ厨房をのぞく成功率が上がり、見られている最中に失敗するとさらに怪しまれる。警戒が60以上になると視線が遠くまで届く
  - 🏪 **店内レイアウト**は店の種類ごとに違う（レトロな喫茶店／焼きたてのパン屋／大衆食堂（カウンター席）／ファストフード店／老舗の洋食屋（ピアノ・ボックス席）／パティスリー（ショーケース）／寿司屋（カウンター席・畳）／トラットリア（ワイン樽）／高級フレンチ）。扉・カウンター・席・隠れ場所の位置や床と壁の雰囲気が変わる
  - 🪴 **隠れる場所**（観葉植物・ついたて・のれん・ピアノ・ワイン樽など、店ごとに2〜3か所）：隠れている間は見つからず、警戒ゲージが少しずつ下がる。席に座っている間もゆっくり下がる
  - 🍽️ 食べる／🔍 厨房をのぞく：確率でその店のレシピを閃く
  - 👀 観察：店員の性格・好きな服の系統・好きな話題／苦手な話題のヒントを探る
  - 💬 話す：話題（料理の腕・お給料・将来の夢・休日・職場の不満・おしゃれ）を選んで好感度を上げる。好きな話題は成功しやすく大きく上がり、苦手な話題は逆効果
  - 好感度 60 で転職の「動機」がわかり、100 になったら「💖 誘う」。動機に合った誘い文句（腕を磨ける／お給料／楽しい職場／夢）を選ぶとアルバイトとして加入。外すと断られる
  - 💰 **買収**（店員の「買収」ボタン）：お金で確実に進められる。格の高い店ほど高く、エースは2.5倍、名店のエースは4倍
    - 💸 心付け：好感度 +30（例：C店 ¥540／S店 ¥840）
    - 🤫 口止め料：警戒ゲージ -40（例：C店 ¥280／S店 ¥440）
    - 📖 レシピを売ってもらう：その店のレシピを確実に入手（例：C店 ¥1,180／S店 ¥3,100、名店は3倍）
    - 💰 引き抜き料：すぐにアルバイトとして加入。好感度が高いほど安く、100なら半額
  - 😍 **メロメロ**：主人公の魅力が店員の「理想の高さ」を大きく上回り、しかも格下の店（自分の店舗ランクで出てくる最高の格より下。名店は格+2として数える）なら、店員が店長に夢中になる
    - 💓 ドキドキ（1格下・魅力が理想の1.2倍以上）：話す成功率 +15%・好感度の上がり方 ×1.5
    - 😍 メロメロ（2格下・1.5倍以上）：成功率 +30%・好感度 ×2・視線で怪しまれない（扇形がピンク）・誘い文句を外しても断られない
    - 💘 イチコロ（3格下・2倍以上）：「💘 スカウト」で魅力だけでその場で加入。街の店カードにも人数が出る
  - 失敗すると**警戒ゲージ**が溜まり、満タンで追い出されて20分出禁。「🚪 撤収」すれば好感度は次回に持ち越し
- **👗 身支度**（👩‍🍳 店長の画面。潜入するときは店のカードからも開ける）：服・頭・顔・小物の4部位を着せ替え。いまは2頭身で表示（約6.5頭身の立ち絵 `stand.js` も用意済みで、`town.js` の `USE_STAND` を `true` にすると切り替わる。部位ごとに PNG へ差し替え可能：`assets/stand/README.md`）。**魅力**（口説く成功率）と**馴染み**（失敗したときの警戒の増えにくさ）が変わり、店のドレスコードに合う系統だと馴染みやすくなります。
  - 同じ系統を3つ以上そろえると**セット効果**（3点：魅力+8／4点：魅力+15・馴染み+3／5点：魅力+22・馴染み+6）
  - 店員ごとに**好きな服の系統**があり、合わせるとその人にだけ魅力が上がる
  - **💇 美容院**（¥500）で髪型（ロング／ツインテール／ポニーテール／ボブ）と髪色を変えられる。髪型にも系統があり、セット効果に数える
- **👑 名店（ボス）**：格の条件を満たすと現れる特別な店（純喫茶ノワール／ワールドバーガー本店／鮨 銀嶺 本店／パティスリー・エトワール／三ツ星 ル・ソレイユ）。普通の店より強く、警戒されやすい。
  - 料理勝負で勝つと**限定アイテム**（ギャルソン服・スターキャップ・割烹着・パティシエ服・星空のドレス）
  - 潜入や勝負で**固有レシピ**（サイフォンコーヒー・トリプルバーガー・おまかせ握り・幻のスフレ・太陽のグランコース）
  - 専用の見た目の**エース**（能力が高く、どれか1つは★5）を口説き落とすと加入。3つそろえると「制覇」
- 引き抜いた店員は、元の店の**制服**（パン屋のバンダナ、ファストフードのキャップ、板前の鉢巻など）のままうちで働きます。
- 野良のお客さんは能力が★1〜2程度（まれに★3）。能力の高い人材やレア料理は引き抜き作戦で手に入れましょう。

## 店長レベルと店舗ランクの違い

| | ⭐ 店長レベル | 🏆 店舗ランク |
| --- | --- | --- |
| 何か | 店長の経験 | お店の大きさ |
| 上がり方 | 接客（1人で経験値1）と調理（料理ごとの経験値）で自動で上がる | 条件（店長レベル・接客人数・正社員の数）を満たしたら、お金を払って自分で上げる |
| 効果 | 新メニューの解禁・魅力（2レベルごとに +1）・来客が少し増える・店舗ランクの条件 | コンロ・テーブル・スタッフ・正社員の枠の上限・敷地（ランク6で2階）・施設・街の店の格 |
| 見る場所 | 上部の ⭐Lv（タップで店長画面） | 上部の店舗ランク表示（タップでランクのタブ） |

## 章と地図

ゲームは4つの章に分かれています。章の最後のランクに上げ、その地域の名店5軒をすべて制覇するとクリアで、次の地域が地図に現れます。解放した地域は自由に行き来できます。

| 章 | 地域 | ランク | 店の強さ・報酬・買収の値段 | 増える国籍 |
| --- | --- | --- | --- | --- |
| 第1章 | 🏘️ 街 | 1〜6 | ×1 | ドイツ・イタリア・イギリス・ポーランド |
| 第2章 | 🚃 首都圏 | 7〜10 | ×2（勝負の強さは +6） | 日本 |
| 第3章 | 🌏 アジア | 11〜14 | ×4（+12） | 中国・韓国・タイ・ベトナム・インド |
| 第4章 | 🌍 世界 | 15〜18 | ×8（+18） | フランス・スペイン・アメリカ・ブラジル・トルコ |

- 店の格は章ごとに E〜S を繰り返します。同じ格でも先の章ほど強く、店員の能力も高めです。
- 第2章以降の名店は、料理勝負で勝つと限定アイテムの代わりに **🏆 名店の証**（人気度 +5）がもらえます。固有レシピとエースは第1章と同じです。
- 次の章のランクに上げるには、前の章のクリアが必要です。第4章をクリアするとエンディングです。

### 2号店・3号店（第2章から）

- ランク7（首都圏デビュー）で2号店（¥200,000）、ランク9（3店舗のチェーン）で3号店（¥500,000）を出せます（お店 → ショップ → 🏬 店舗）。
- 店ごとに設備・施設・内装・配置・スタッフを持ちます。スタッフの上限は店ごと、正社員の枠と店舗ランクは会社全体で1つです。
- カフェ画面の右上で表示する店を切り替えます。店長（主人公）はいつも表示している店にいます。
- スタッフタブの「🚚 異動」でスタッフを別の店へ移し、「🎖️ 店長代理に」で正社員をその店の店長代理に任命します。
- 表示していない店は、店長代理（休憩中・外出中でない正社員）がいる間だけ、留守中の営業と同じ計算で営業を続けます。

## 敷地・2階・施設

- **敷地**：ランクが上がるたびに、店の正面の壁が外へ広がって客席が広くなります（縮小もスクロールもしません）。壁より手前は店の外（歩道）で、お客さんは正面の入口から入ってきます。
- **2階**：ランク6（2階席のある名店）で2階ができます。カフェ画面左上の「1F／2F」で表示を切り替えます。2階は客席だけで、スタッフとお客さんは階段（片道5秒）で行き来します。11卓目からのテーブルは2階に置かれ、配置の編集の「⇅ 別の階へ」でテーブルを階の間で移せます。スタッフタブで、ホールの仕事をする階（両方の階／1Fだけ／2Fだけ）を決められます。
- **施設（ショップの「🏗️ 施設」）**

| 施設 | 作れるランク | 費用 | 効果 |
| --- | --- | --- | --- |
| 🥡 テイクアウト窓口 | カフェ | ¥6,000 | 正面の壁の窓口で、席を使わずに料理が売れる |
| 🍲 仕込み設備 | カフェ（2台目は有名店） | ¥5,000（2台目 ¥20,000） | 長時間料理を作れる |
| 🚪 個室 | 人気カフェ | ¥15,000 | VIP専用の席。VIPはカウンターでいちばん高い料理を頼み、代金が3倍 |
| ☀️ テラス席 | 人気カフェ | ¥12,000 | 正面の壁の外にもテーブルを置ける（テーブルの上限 +2）。天気が1時間ごとに変わり、晴れは来客が増え、雨はテラス席が休み |
| 🛗 エレベーター | 2階席のある名店 | ¥40,000 | 2階への移動が5秒 → 1.5秒 |

スタッフの人数は店長を含みます。正社員の枠は ランク1〜6 で 1・2・4・5・7・8 人です（ランクアップの条件の正社員の人数を必ず満たせる数）。

設備強化は「コンロ強化」（調理速度 +15%・1回にできる量 +1人前／Lv）と「テーブル強化」（代金 +10%・待てる時間 +10%／Lv）の2種類です。

画面は下部メニューで切り替えます。

- **☕ カフェ**：お店の様子を画面いっぱいに表示（お客さんのスカウト、お店のできごと）。右上の「🛠 配置」で**配置の編集**ができます。テーブル・コンロ・観葉植物・レコードプレーヤーをドラッグして好きな場所へ動かせます（テーブルは客席、コンロは厨房の中。テーブル同士・コンロ同士が重なる場所には置けません）。「↺ 最初の配置」で元に戻せます。置き場所によってスタッフの歩く距離が変わります。買い足したテーブル・コンロは空いている場所に置かれます
- **🏪 お店**：お店のこと。「調理」「スタッフ」「ショップ」「🏆 ランク」のタブがあります（上の店舗ランクの表示をタップするとランクのタブが開き、ランクアップできるときは光ります）
- **👩‍🍳 店長**：自分のこと。ステータス（魅力・馴染み・セット効果）、身支度・美容院、お店の記録、設定（遊び方・データ消去）
- **🗺️ 地図**：外のこと。地域（章）の切り替えと、引き抜き作戦（料理勝負・潜入）

進行状況はブラウザ（localStorage）に自動で保存されます。

## 起動方法

`index.html` をブラウザで開くだけで遊べます。ビルドは不要です。

GitHub Pages で公開する場合は、リポジトリの **Settings → Pages** で
「Deploy from a branch」→ ブランチ `main`・フォルダ `/ (root)` を選んで保存してください。

## スマホにアプリとして入れる（PWA）

GitHub Pages で公開したページを開き、次の方法でホーム画面に追加します。
追加したあとはアイコンから全画面で起動でき、オフラインでも遊べます。

- **iPhone / iPad**：Safari で開く → 共有ボタン → 「ホーム画面に追加」
- **Android**：Chrome で開く → メニュー（︙）→ 「アプリをインストール」または「ホーム画面に追加」
- **パソコン**：Chrome / Edge で開く → アドレスバー右端のインストールボタン

ゲームを更新したときは `sw.js` の `CACHE` の番号（`eikyu-cafe-v29` → `v30`）を上げてください。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `style.css` | 見た目 |
| `game.js` | ゲームのロジック・描画・保存 |
| `chara.js` | 2頭身キャラクター（主人公の着せ替えを含む）の SVG 生成 |
| `stand.js` | 主人公の立ち絵（約6.5頭身・レイヤー式。PNG に差し替え可能） |
| `town.js` | 街・引き抜き作戦（料理勝負・潜入）・身支度 |
| `manifest.webmanifest` | アプリ名・アイコンなど PWA の設定 |
| `sw.js` | オフラインで遊ぶためのサービスワーカー |
| `icons/` | アプリのアイコン |
