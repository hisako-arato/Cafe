# ☕ 永久雇用カフェ

お客さんをスカウトしてアルバイトとして雇い、**永久雇用契約**を結んで**正社員**にしていくカフェ経営ゲームです。
ブラウザだけで動き、スマホでもパソコンでも遊べます。

## 遊び方

1. 下部メニューの**厨房**でコンロをタップして料理を注文すると、手の空いたスタッフがコンロに入って調理します（数秒〜3分）。できあがったらタップしてカウンターへ並べます。
2. スタッフがカウンターの料理をお客さんへ運び、食べ終わるとお金がもらえます。お客さんは基本的に安い料理から頼みます。汚れたテーブルもスタッフが片付けます。スタッフの仕事は「配膳 → 調理 → 片付け」の順に優先されます。
3. 待たせすぎるとお客さんは怒って帰ってしまいます。
4. お客さんを**タップするとスカウト**できます。雇った人はまず**アルバイト**で、契約期間（5分）が終わると辞めてしまいます。
5. **📜 永久雇用契約**を結ぶと**正社員**になり、ずっと働いてくれます。契約書はレベルアップかショップで手に入ります。
6. お金で**コンロ・テーブル・内装**を増やしてお店を大きくしましょう。

進行状況はブラウザ（localStorage）に自動で保存されます。

## 起動方法

`index.html` をブラウザで開くだけで遊べます。ビルドは不要です。

GitHub Pages で公開する場合は、リポジトリの **Settings → Pages** で
「Deploy from a branch」→ ブランチ `main`・フォルダ `/ (root)` を選んで保存してください。
数分後に `https://hisako-arato.github.io/Cafe/` で遊べるようになります。

## スマホにアプリとして入れる（PWA）

GitHub Pages で公開したページを開き、次の方法でホーム画面に追加します。
追加したあとはアイコンから全画面で起動でき、オフラインでも遊べます。

- **iPhone / iPad**：Safari で開く → 共有ボタン → 「ホーム画面に追加」
- **Android**：Chrome で開く → メニュー（︙）→ 「アプリをインストール」または「ホーム画面に追加」
- **パソコン**：Chrome / Edge で開く → アドレスバー右端のインストールボタン

ゲームを更新したときは `sw.js` の `CACHE` の番号（`eikyu-cafe-v3` → `v4`）を上げてください。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `style.css` | 見た目 |
| `game.js` | ゲームのロジック・描画・保存 |
| `chara.js` | 2頭身キャラクターの SVG 生成 |
| `manifest.webmanifest` | アプリ名・アイコンなど PWA の設定 |
| `sw.js` | オフラインで遊ぶためのサービスワーカー |
| `icons/` | アプリのアイコン |
